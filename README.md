# MA2806-Data-Journalism-Visualisation
## Project Theme 
This project explores diversity (or lack thereof) in bestselling fiction, looking at three different 'bestseller' lists to do so. We have collected data about each book on these lists, including information about the author's ethnicity, language and country of origin of the book, genre, the date the book was published and other factors that we felt were important. 
## Description
The user will be able to explore the data we have collected through interacting with the interface. There is a 'filter' button where the user can choose to filter the stack to only show books which fit a certain criteria (e.g; only seeing fantasy novels). In addition to this, you are able to click on the spines of each book and see the key characteristics of the book and of the person who wrote it. 
## Aesthetics
<img width="1615" height="899" alt="image" src="https://github.com/user-attachments/assets/2299f00d-1005-434b-a500-cdafe0a60d1e" />
This was our original plan for the aesthetics of our project. Our colour palette remained largely pastel with a darker background to create contrast. In addition to this, the main aesthetic idea that we were interested in is having the spines of the books visible to the user and for the books to appear to be stacked on the screen. It was also important to us to have the stack changing in size in a smooth way, as if the books were falling, rather than the stack snapping to decrease in size, as we found that this made using the interface smoother.
